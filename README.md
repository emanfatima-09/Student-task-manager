# Student-task-manager
Student Task Management System for team activity
## Definition of Done (DoD)
1. The code runs with zero syntax or runtime errors.
2. The feature is developed on a separate branch (not directly on `main`).
3. A Pull Request is created and linked to its GitHub Issue.
4. At least one teammate performs a peer review and leaves a comment.
5. All review comments are resolved before merging into `main`.
